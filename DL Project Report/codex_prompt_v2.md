```python
def overlay_heatmap(
    pil_image: Image.Image,
    scores_24x24: np.ndarray,
    mask_24x24: np.ndarray,
) -> Image.Image:
    """Render top-k selection overlay: only selected tokens are highlighted,
    with score-modulated alpha. Unselected regions show the raw image."""
    import matplotlib.cm as cm

    img = pil_image.convert("RGB").resize((336, 336))
    base = np.array(img).astype(np.float32) / 255.0  # (336, 336, 3)

    # Per-image score normalization on selected tokens only (for color contrast).
    sel = scores_24x24 * mask_24x24
    if sel.max() > sel.min():
        sel_norm = (sel - sel[mask_24x24 > 0].min()) / (sel.max() - sel[mask_24x24 > 0].min() + 1e-8)
        sel_norm = np.clip(sel_norm, 0.0, 1.0) * mask_24x24
    else:
        sel_norm = mask_24x24.astype(np.float32)

    # Upsample to 336x336.
    sel_full = np.kron(sel_norm, np.ones((14, 14)))
    mask_full = np.kron(mask_24x24, np.ones((14, 14)))

    # Color the SELECTED tokens with a warm overlay (red-yellow), modulated by score.
    cmap = cm.get_cmap("YlOrRd")
    color = cmap(sel_full)[..., :3]  # (336, 336, 3)
    # Alpha: 0 for unselected; ramp 0.35 -> 0.75 for selected (modulated by score).
    alpha = np.where(mask_full > 0, 0.35 + 0.40 * sel_full, 0.0)[..., None]

    blended = base * (1.0 - alpha) + color * alpha
    blended = np.clip(blended * 255.0, 0, 255).astype(np.uint8)

    # Optional thin grid lines at every 14px to expose the patch structure.
    out = Image.fromarray(blended)
    from PIL import ImageDraw
    draw = ImageDraw.Draw(out)
    for k in range(0, 337, 14):
        draw.line([(k, 0), (k, 336)], fill=(255, 255, 255, 32), width=1)
        draw.line([(0, k), (336, k)], fill=(255, 255, 255, 32), width=1)
    return out
```

\begin{abstract}
We document three training-dynamics pathologies that arise whenever a
trainable visual-token selector is co-optimized with LLM adapters before
the LLM. \emph{Co-adaptation oscillation} produces limit cycles whose
period scales as $1/\eta_\text{selector}$, verified across $25{\times}$
in selector learning rate. \emph{BudgetPredictor collapse} sends per-sample
token budgets to $k_{\max}$ whenever $\lambda_b\!\leq\!0.05$, with a narrow
stable window of $[0.08, 0.15]$. \emph{Warm-start dependence} prevents
from-scratch convergence at LLaVA-1.5 scale across two selector variants
and three LoRA capacities. We sidestep each pathology with a parameter-free
token merge (closes the loop by construction), a calibrated $\lambda_b$,
and a staged curriculum on a converged base. The resulting system
(TC-ViTok) runs at $4{\times}$ compression on LLaVA-1.5-7B with a measured
cost of $-4.1$ VQAv2, $-3.4$ GQA, $-7.4$ POPE points against a matched
LoRA-576 control --- a cost we report rather than hide, and one that
bounds how much accuracy the named failure modes still leave on the table.
\end{abstract}
